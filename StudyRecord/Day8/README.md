## AdversarialAttack

### 实验方法

notebook 主要实现了以下内容：

1. 良性样本评估  
   先在未攻击的原始图像上评估模型准确率，作为后续对比基线。

2. FGSM 攻击  
   使用单步梯度符号法，根据损失对输入求梯度，并沿梯度方向施加一次扰动。

3. I-FGSM 攻击  
   在 FGSM 的基础上进行多步迭代更新，每一步使用较小步长，并将结果限制在合法扰动范围内。

4. 对抗样本保存  
   将生成后的对抗图像恢复为 `uint8` 图片，分别保存到 `fgsm/` 和 `ifgsm/` 目录，并打包为 `.tgz` 文件用于提交。

5. 可视化分析  
   对比原图与攻击后图像的预测类别与置信度，直观观察攻击效果。

6. 被动防御示例  
   notebook 最后使用 JPEG 压缩作为简单被动防御，对单张对抗样本进行压缩后再送入模型预测，观察分类是否有恢复迹象。

### 实验结果

根据 notebook 当前运行结果：

| 数据状态 | Accuracy | Loss | 说明 |
| --- | ---: | ---: | --- |
| 原始图片 | 0.95000 | 0.22686 | 模型在良性样本上表现较好 |
| FGSM 对抗样本 | 0.60000 | 2.46173 | 单步攻击已明显降低准确率 |
| I-FGSM 对抗样本 | 0.01000 | 17.42791 | 多步迭代攻击几乎完全破坏分类结果 |

从结果可以看出：

- 原始样本上模型准确率约为 95%，说明预训练模型在该 200 张图像上有较强识别能力。
- FGSM 作为单步攻击，已经能将准确率从 95% 降到 60%，说明模型对输入扰动较敏感。
- I-FGSM 进一步将准确率压到 1%，说明迭代式攻击在相同扰动约束下更具破坏性。

### 结果分析

本实验反映出两个比较直接的现象：

- 深度学习模型即使在原始样本上性能较好，也可能对微小但有方向性的扰动非常脆弱。
- 相比一次性扰动，迭代式攻击能够更精确地朝着提升损失的方向逼近，因此攻击效果更强。

### 被动防御观察

实验最后使用 JPEG 压缩作为被动防御示例。其核心思路是通过有损压缩削弱对抗扰动中的高频噪声成分，再重新送入模型进行预测。

这一方法的特点是：

- 实现简单，不需要重新训练模型
- 适合作为输入预处理防御的基础示例
- 防御效果通常有限，且可能同时损伤正常图像信息

当前 notebook 中该部分主要是单样本演示，因此更适合作为现象观察，而不是严格的定量结论。
